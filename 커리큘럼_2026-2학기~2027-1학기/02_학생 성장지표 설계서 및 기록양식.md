# 학생 성장지표 설계서 및 기록양식
### "학생이 자기 성장을 눈으로 보게 하는" 5개 지표

작성: 박소명 | 기준일 2026. 9. 10. | 짝 문서: `01_수학반 커리큘럼_2026.09-2027.04.md`


> **개인정보 안내** — 이 사본은 공개 저장소에 올라가는 판본이라 학생 이름을 A~J 코드로 바꿨습니다.
> 실명이 들어간 원본은 `_비공개/` 폴더(저장소에서 제외됨)에 있고, 대조표는 담당 교사가 보관합니다.

---

## 1. 설계 원칙

지금 프로그램(태청야학 수학 앱)에는 이미 좋은 지표가 많습니다. 정답률, 학습 모멘텀, 신호등, 망설임 패턴, 답안 수정 패턴, 영역 상대 성취도, 자기주도 탐색 — 다만 이것들은 **교사가 개입 시점을 판단하기 위한 지표**입니다. 학생에게 그대로 보여주면 오히려 위축됩니다.

그래서 지표를 두 층으로 분리합니다.

| 층 | 이름 | 보는 사람 | 성격 | 개수 |
|---|---|---|---|---|
| 안쪽 | **분석 지표** | 교사만 | 정답률·모멘텀·행동 패턴 등 진단용 | 기존 그대로 |
| 바깥 | **성장 지표** | 학생 + 교사 | 셀 수 있고, 늘어나기만 하고, 오늘 바로 바뀌는 것 | **5개** |

### 학생용 지표가 지켜야 할 4가지 규칙

1. **셀 수 있어야 한다.** 퍼센트보다 개수. "정답률 73%"보다 "혼자 풀 수 있는 유형 9개".
2. **줄어들지 않아야 한다.** 누적형 지표를 씁니다. 못한 주가 있어도 숫자가 깎이지 않습니다.
3. **한 눈에 목표가 보여야 한다.** 모든 지표에 목표선이 있습니다. (예: 12개가 합격선)
4. **틀린 것을 자산으로 바꾼다.** 오답 개수는 절대 보여주지 않고, **"다시 맞힌 개수"**만 보여줍니다.

> 학생 B 학생처럼 학업적 자기효능감이 낮은 경우, 이 5개 지표 자체가 개입 수단입니다. 성장 추이를 보여드리는 것이 곧 수업입니다.

## 2. 학생용 성장 5지표

### 지표 ① 🏁 합격 게이지 — "20개 중 몇 개를 혼자 풀 수 있나"

| 항목 | 내용 |
|---|---|
| 정의 | 고졸 검정고시 20유형 중 **★★ 이상**으로 판정된 유형 수 |
| 표시 | `9 / 20` + 12칸에 합격선 표시가 있는 게이지 바 |
| 목표 | **12개** (= 60점 = 수학 과목 합격) |
| 수집 | 수업 ④ 블록에서 교사가 ★판정 (§3) |
| 갱신 | 매주 |
| 학생에게 하는 말 | "지난달에 7개였는데 오늘 9개가 되셨습니다. 합격까지 3개 남았어요." |

- 중졸 트랙은 `n / 25`(중졸 25문항), 다솜반은 `n / 이번 학기 목표 단원 수`로 같은 형식을 씁니다.

### 지표 ② 🌳 이해 나무 — "영역별로 얼마나 자랐나"

| 항목 | 내용 |
|---|---|
| 정의 | 3개 영역의 성장 단계. 앱 홈 화면의 나무 기능을 그대로 씁니다 |
| 영역 | **계산의 힘** / **도형과 좌표** / **검정고시 수학** |
| 단계 | 🌱 씨앗(~40%) → 🌿 새싹(~75%) → 🌳 나무(~90%) → 🍎 열매(90%+) |
| 수집 | 앱이 자동 집계 (영역별 정답률) |
| 갱신 | 학생이 앱에서 문제를 풀 때마다 실시간 |
| 학생에게 하는 말 | "도형 나무에 잎이 무성해졌습니다. 계산 나무에 물을 조금 더 주면 되겠어요." |

- 숫자(%)는 **학생 카드에 쓰지 않습니다.** 그림 단계만 씁니다.

### 지표 ③ 🔁 다시 맞힌 문제 — "되찾은 문제"

| 항목 | 내용 |
|---|---|
| 정의 | 예전에 틀렸던 문제를 **다시 만나 맞힌 누적 개수** |
| 표시 | 누적 숫자 + 이번 주 증가분 (`총 34개  (이번 주 +3`) |
| 목표 | 없음 (계속 늘어나는 숫자) |
| 수집 | 수업 ② 블록(오답 문제지 재도전) + 앱 오답 재출제 |
| 갱신 | 매주 |
| 학생에게 하는 말 | "틀린 문제 3개를 오늘 되찾으셨습니다. 이게 진짜 실력이 되는 순간입니다." |

- **이 지표가 5개 중 가장 중요합니다.** 시니어 학습자에게 "틀렸다"를 "되찾았다"로 번역해 주는 장치입니다.

### 지표 ④ 📅 꾸준함 도장 — "얼마나 함께했나"

| 항목 | 내용 |
|---|---|
| 정의 | 수업 출석 도장 + 앱 학습 도장 |
| 표시 | 도장판 (한 달 = 칸 여러 개). 연속 주간 수는 **표시하지 않음** |
| 목표 | 월 4개 이상 |
| 수집 | 출석부 + 앱 `activeDates` |
| 갱신 | 매주 |
| 학생에게 하는 말 | "이번 달에 도장 6개를 모으셨습니다." |

- **연속 기록(streak)은 쓰지 않습니다.** 생업으로 한 주 빠졌을 때 0으로 돌아가는 지표는 시니어 학습자에게 이탈 요인이 됩니다. 누적 개수만 씁니다.

### 지표 ⑤ 🗣️ 설명 배지 — "말로 설명할 수 있었나"

| 항목 | 내용 |
|---|---|
| 정의 | 수업 중 풀이 과정이나 개념을 **말로 설명한 횟수** (정답 여부 무관) |
| 표시 | 배지 개수 |
| 목표 | 회차당 1개 (= 수업 원칙 "모두 한 마디 이상") |
| 수집 | 수업 ③ 블록에서 교사가 이름 옆에 체크 |
| 갱신 | 매주 |
| 학생에게 하는 말 | "오늘 설명해 주신 덕분에 다른 분들도 이해하셨어요. 배지 하나 더." |

- 능동적 학습자 양성이라는 수업 목적을 직접 측정하는 유일한 지표입니다. **틀리게 설명해도 배지를 줍니다.**

### 5지표 한눈 요약

## 3. 핵심 규칙 — 유형 숙달 ★ 판정 기준

지표 ①이 신뢰를 얻으려면 판정이 흔들리지 않아야 합니다. 아래 4단계를 그대로 씁니다.

| 단계 | 표시 | 판정 기준 | 관찰 방법 |
|---|---|---|---|
| 0 | ☆ | 아직 배우지 않았거나 손대지 못함 | 백지 |
| 1 | ★ | **도움을 받아** 풀이 완성 | 교사가 힌트를 준 경우, 예제를 보고 따라 푼 경우 |
| 2 | ★★ | **혼자** 정확히 풀이 (1회) | 순회 중 개입 없이 완성 |
| 3 | ★★★ | **다른 날 2회 연속** 혼자 정확히 풀이, 또는 풀이를 말로 설명 | 3-1-1 복습 때 다시 확인 |

**판정 규칙**
- ★★ 이상만 **합격 게이지에 포함**합니다.
- 판정은 **④ 혼자 풀기 블록에서만** 합니다. 함께 푼 ③ 블록의 결과로는 판정하지 않습니다.
- 3주 뒤 복습에서 틀리면 ★★★ → ★★ 로 내립니다. **단, 학생 카드에서는 숫자를 깎지 않고 "다시 확인 중"으로 표시**합니다.
- 한 유형당 실전 문항 **2문항 이상**을 근거로 판정합니다. 1문항은 우연일 수 있습니다.

## 4. 수집 지침 — 90분 동안 무엇을 언제 기록하는가

| 시간 | 블록 | 교사가 손에 드는 것 | 기록 동작 (총 소요) |
|---|---|---|---|
| 19:00–19:10 | ① 워밍업 | 출석부 | 출석 도장 체크 (30초) |
| 19:10–19:25 | ② 되돌아보기 | 주간 기록표 | 학생별 "다시 맞힌 개수" 숫자만 적기 (1분) |
| 19:25–19:55 | ③ 오늘의 유형 | 주간 기록표 | 설명한 학생 이름 옆에 체크 (수시, 0초 수준) |
| 19:55–20:20 | ④ 혼자 풀기 | 주간 기록표 | **순회하며 ★판정**. 도움을 줬으면 그 자리에서 ★ 하나만 (순회 중 처리) |
| 20:20–20:30 | ⑤ 마무리 | 성장카드 | 학생이 직접 자기 카드에 오늘 칸을 채움 (교사는 확인만) |

**수집의 3원칙**

1. **수업 중에 다 끝냅니다.** 집에 가서 정리하는 방식은 3주를 못 넘깁니다. 위 표의 기록 동작은 합쳐서 **2~3분**입니다.
2. **학생이 자기 카드를 직접 채웁니다.** 교사가 채워주면 성적표가 되고, 학생이 채우면 성장 기록이 됩니다.
3. **판정은 순회하면서, 종이 위에서.** 태블릿·노트북으로 입력하려 하면 순회가 끊깁니다. 종이에 적고 주말에 앱과 대조하십시오.

**주중 (교사 5분 루틴)**
- 수요일: 앱 `학생관리` → 신호등 확인 → 노랑·빨강 학생에게 피드백 1줄.
- 목요일: 오답 문제지 출력 + 유형 지도 갱신 (주간 기록표 → 학생별 유형 지도로 전사).

## 6. 성장카드 — 학생에게 드리는 물건

- **형태**: A4 1장, 앞면만. 글자 크게, 그림 위주. 코팅해서 매달 스티커를 붙이거나, 매달 새로 인쇄해 드립니다.
- **발급 주기**: 월 1회 (매월 마지막 수업) + 12월 학기말 + 4월 시험 직전.
- **전달 방식**: 봉투에 넣어 **이름을 부르며 한 사람씩** 드립니다. 이때 지표 ①의 증가분을 소리 내어 읽어 드립니다.
- **HTML 서식**: `03_학생 성장카드.html` — 브라우저에서 열어 학생 이름·숫자만 바꾸고 인쇄(Ctrl+P)하면 됩니다.

### 성장카드에 쓰지 말아야 할 것

- 정답률 퍼센트, 다른 학생과의 비교, 등수, 틀린 문제 수, 연속 출석 기록, "부족", "미흡" 같은 단어.
- 예측 점수(예: "현재 45점 예상")도 쓰지 않습니다. **합격 게이지의 남은 개수**로만 이야기합니다.

### 앱에 추가하면 좋을 것 (우선순위 순)

1. **유형 숙달 ★ 저장 필드** — 학생 문서에 `mastery: { u1: 2, u2: 3, ... }` 를 두고, 교사 대시보드 학생 상세에 20칸 그리드로 입력. → 지표 ①이 종이에서 앱으로 넘어옵니다. **가장 효과가 큽니다.**
2. **합격 게이지 위젯** — 학생 홈 최상단에 `★★ 이상 개수 / 20`, 12칸에 합격선 표시.
3. **"다시 맞힌 문제" 카운터** — 오답으로 기록된 유형을 다시 맞혔을 때 `recovered += 1` 누적 저장 (현재는 세션 단위로만 계산됨).
4. **성장카드 인쇄 버튼** — 교사 대시보드에 학생 선택 → 5지표를 채운 A4 1장 출력. 만능학습지의 인쇄 파이프라인(`SHEET_CSS`)을 재사용하면 됩니다.
5. **설명 배지 입력** — 교사 대시보드에 회차별 체크박스 한 줄.

> 참고: `js/` 파일을 수정하면 반드시 `scripts_rebuild_index.py` 를 실행해 `index.html` 을 재생성해야 배포본에 반영됩니다.

## 8. 지표를 쓸 때 조심할 것

- **지표가 목적이 되지 않게.** 합격 게이지를 올리려고 ★판정을 후하게 주면 3월 모의고사에서 그대로 드러납니다. 판정 기준(§3)을 지키는 것이 결국 학생을 지킵니다.
- **데이터가 적은 초기에는 해석하지 않습니다.** 9~10월에는 숫자를 보여주기보다 "지도가 그려지고 있다"고 말해 주십시오.
- **앱 지표는 앱을 쓴 학생에게만 유효합니다.** 학생 C·학생 J 학생처럼 출석이 어려운 경우, ②④는 낮게 나옵니다. 이때 ③⑤를 중심으로 이야기하십시오.
- **행동 패턴 지표(망설임·수정)는 학생에게 절대 보여주지 않습니다.** 교사가 개입 방식을 고르는 용도입니다. 예를 들어 "수정 없이 오답(fixated)"이 많으면 오개념이 굳은 것이므로 문제를 더 주는 대신 **개념을 다시 설명**해야 합니다.
