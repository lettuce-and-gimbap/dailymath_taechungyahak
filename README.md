# 태청야학 수학 학습 도우미

야학 학생들을 위한 수학 학습 웹앱 (React + Firebase, 번들러 없이 `index.html` 하나로 배포).

## 📐 만능 학습지 (선생님 탭)

좌표를 중심으로 고졸 검정고시 수학 **전 영역(1번~20번)** 을 다루는 학습지 생성기.

- 프리셋: ★ 좌표 완전정복 · 🌱 좌표 워밍업 · 📐 도형의 방정식 · 📘 전 영역 1~20번 · 🌍 전체
- 유형(26개)마다 **개념 카드 → 풀이 예시 → 실전 문항** 자동 생성, 문항별 조건 숫자 편집 · 새 숫자 · 추가 · 삭제
- 개념 카드는 초등 5학년 수준의 설명 · 그림 · 예시 · 팁으로 구성하고, **선생님이 글을 직접 고칠 수 있다**
- **개념 빈칸 뚫기** 토글 — 핵심 낱말이 밑줄 빈칸이 되고, 정답 보이기를 켜면 답이 나타난다
- 좌표 중심 유형(★ 기초 1~3, 7·10·11·12·13·14·18번)은 큰 좌표평면 그림과 "눈금 읽기" 단계별 풀이 포함
- 사지선다 / 서술형 전환, 정답 보이기, 글자 크기, 실전문제 2단 인쇄, 글자 편집(덮어쓰기)
- **작업대**: 새로 만들어도 이전 학습지가 지워지지 않고 쌓인다. 장마다 접기/펼치기 토글
- 학습지마다 **저장**(Firestore `gedSheets`) · **반출**(인쇄/PDF · 새 탭 · JSON) · **삭제**, 자동 임시저장

코드: `js/worksheet/gedCore.js`(엔진) · `js/worksheet/gedConcepts.js`(개념 설명) · `js/worksheet/gedUnits.js`(문제 생성) · `js/teacher/gedWorksheet.js`(탭)

## 폴더 구조

`js/` 는 **계층 → 도메인** 순서로 나눈다. 아래 계층은 위 계층만 알고, 위 계층은 아래를 모른다.

| 폴더 | 역할 |
|---|---|
| `core/` | 상수 · 공용 도우미 · 기출 매핑 · 로그 지표 · Firestore 접근 |
| `math/` | 수식 표기 · 그래프 미리보기 · 그래프 SVG (여러 화면 공용) |
| `generators/` | 문제 생성기 (`elementary` · `middle` · `high/` 영역별) |
| `worksheet/` | 만능 학습지 엔진 |
| `ui/` | 로그인 · 스플래시 · 인쇄 모달 (학생·선생님 공용) |
| `student/` | 학생 화면 — 홈 · 문제풀기 · 기하학 · 모의고사 · 기록 · 숙제 |
| `teacher/` | 선생님 화면 — 학생관리 · 상세분석 · 오답노트 · 공지 · 학습지 |

## 개발 메모

`js/` 아래를 고친 뒤에는 반드시 `scripts_rebuild_index.py` 를 실행해 `index.html` 을 다시 만든다.
`index.html` 은 `js/` 를 이어 붙인 결과물이라 직접 고치지 않는다. 자세한 내용은 `CLAUDE.md` 참고.
