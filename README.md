# 태청야학 수학 학습 도우미

야학 학생들을 위한 수학 학습 웹앱 (React + Firebase, 번들러 없이 `index.html` 하나로 배포).

## 📐 만능 학습지 (선생님 탭)

좌표를 중심으로 고졸 검정고시 수학 **전 영역(1번~20번)** 을 다루는 학습지 생성기.

- 프리셋: ★ 좌표 완전정복 · 🌱 좌표 워밍업 · 📐 도형의 방정식 · 📘 전 영역 1~20번 · 🌍 전체
- 유형(23개)마다 **개념 카드 → 풀이 예시 → 실전 문항** 자동 생성, 문항별 조건 숫자 편집 · 새 숫자 · 추가 · 삭제
- 좌표 중심 유형(★ 기초 1~3, 7·10·11·12·13·14·18번)은 큰 좌표평면 그림과 "눈금 읽기" 단계별 풀이 포함
- 사지선다 / 서술형 전환, 정답 보이기, 글자 크기, 실전문제 2단 인쇄, 글자 편집(덮어쓰기)
- 인쇄·PDF(새 창), 새 탭 열기, Firestore 저장/불러오기(`gedSheets`), JSON 내보내기/불러오기, 자동 임시저장

코드: `js/worksheet/gedCore.js`(엔진) · `js/worksheet/gedUnits.js`(유형) · `js/components/gedWorksheet.js`(탭)

## 개발 메모

`js/` 아래를 고친 뒤에는 반드시 `scripts_rebuild_index.py` 를 실행해 `index.html` 을 다시 만든다. 자세한 내용은 `CLAUDE.md` 참고.
